# Shiksha Prabhat Public School - ERP & Website

A premium, modern, and production-ready School Management System and Landing Page.

## Tech Stack
* **Frontend:** Next.js 15, Tailwind CSS, ShadCN UI, Framer Motion, Recharts
* **Backend:** NestJS, Prisma ORM, PostgreSQL (Aiven)
* **Design:** Glassmorphism, Premium SaaS UI
